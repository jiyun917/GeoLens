Workflow cont'd:
9. Pick the first fault stick: either Left-click + drag or Left-click to pick and double-click to end a stick.
10. Edit as needed: Left-click + drag seeds, Ctrl + Left-click to remove seeds, or Ctrl + Z to undo the last action, or Ctrl + Y to redo.
To be able to pick fault sticks make sure that:
1) Position mode is selected.
2) The fault stick set is selected in the tree.
3) Edit Sticks icon is toggled on.
